# Revenue Opportunity Patterns

Este archivo contiene patrones comunes de generación de ingresos que el modelo puede usar como inspiración al proponer oportunidades.

No son ideas concretas, sino **estructuras de negocio repetibles**.

---

# 1. Automatización de procesos

Patrón:
Identificar un proceso manual repetitivo que empresas o profesionales hacen constantemente y automatizarlo.

Ejemplos:
- generación automática de reportes
- scraping de datos
- consolidación de dashboards
- limpieza de datos
- generación de documentos

Modelo de ingresos:
- suscripción mensual
- fee por uso
- servicio productizado

---

# 2. Micro SaaS

Patrón:
Herramientas pequeñas que resuelven un problema muy específico.

Características:
- nicho claro
- funcionalidad limitada pero útil
- bajo costo de desarrollo
- pricing simple

Ejemplos:
- dashboards específicos
- alertas automatizadas
- calculadoras de negocio
- herramientas de análisis

---

# 3. Productos basados en datos

Patrón:
Convertir datos difíciles de conseguir en productos de información.

Ejemplos:
- benchmarks de mercado
- reportes sectoriales
- monitoreo de precios
- inteligencia competitiva
- alertas de mercado

Modelo de ingresos:
- suscripción
- reportes premium
- acceso API

---

# 4. Servicios productizados

Patrón:
Tomar un servicio de consultoría y convertirlo en una oferta estandarizada.

Ejemplos:
- auditoría de funnels
- optimización de pricing
- setup de analytics
- análisis de competidores

Características:
- entregable claro
- precio fijo
- proceso repetible

---

# 5. Herramientas internas convertidas en producto

Patrón:
Muchas empresas crean herramientas internas que luego pueden venderse.

Ejemplos:
- dashboards internos
- scripts de automatización
- plantillas
- workflows

---

# 6. Agregadores de información

Patrón:
Recolectar información dispersa y presentarla de forma útil.

Ejemplos:
- comparadores de precios
- agregadores de noticias sectoriales
- alertas de cambios regulatorios
- monitoreo de competidores

---

# 7. AI wrappers

Patrón:
Tomar un modelo de IA y aplicarlo a un problema específico.

Ejemplos:
- generación automática de reportes
- análisis de datos
- copilots para nichos específicos
- clasificación de información

---

# Señales de buena oportunidad

- problema repetitivo
- usuario con dolor claro
- posibilidad de cobrar rápido
- nicho con poca competencia
- acceso diferencial a datos
- posibilidad de validación rápida

---

# Riesgos comunes

- mercado demasiado chico
- tiempo al primer revenue muy largo
- dependencia excesiva de un solo cliente
- solución sin problema real
- falta de distribución
